    Alcance de este prototipo

    • Los datos se almacenan localmente en este navegador y no se sincronizan entre dispositivos.
    • Las rutas públicas son locales y pueden no funcionar fuera de este equipo.
    • Las fotografías deben permanecer en el proyecto o usar un formato compatible con el navegador.
    • No se afirma cumplimiento legal automático; la implantación real requiere revisión organizativa y jurídica.

    NextCards no envía estos datos a un servidor. Desactivar la analítica detiene los eventos nuevos; no elimina el historial existente.
